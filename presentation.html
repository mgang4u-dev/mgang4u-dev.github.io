Tip 01

작업 속도 대폭 향상
# 권한 확인 없이 실행 claude --dangerously-skip-permissions # 또는 설정에서 허용 모드 선택 /permissions
Tip 02
CLAUDE.md — 프로젝트 규칙 정의
매번 설명하지 말고, 규칙을 파일로 남기자
# CLAUDE.md 예시 # 배포 - 서버 배포 시 git commit + push 먼저 - SSH: rocky@100.113.167.49 # 코드 스타일 - TypeScript 사용, 한국어 주석 - 테스트 필수 # 금지 사항 - node_modules 커밋 금지 - .env 파일 커밋 금지

프로젝트 루트에 CLAUDE.md를 두면 Claude가 자동으로 읽고 규칙을 따릅니다.
반복 지시를 줄이고 일관된 결과를 얻을 수 있습니다.

Tip 04
진행 방식 선택
상황에 따라 다르게 접근
에이전트 팀 구성 단계적 진행
언제 빠르게 밀어야 할 때 정확도가 중요할 때
방식 서브에이전트 병렬 실행 한 단계씩 확인하며 진행
장점 속도 안정성
적합한 작업 CRUD, 반복 작업, 리팩토링 아키텍처 설계, 복잡한 로직
Tip 05
기술 스택도 AI와 함께 선정

1. 서비스 요구사항 정리
2. Claude에게 스택 추천 요청
3. 추천 근거 확인
4. 최종 선택 후 진행
